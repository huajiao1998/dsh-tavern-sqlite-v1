# DSH Tavern SQLite V1

**让长对话存档少做重复读写，让剧情回退真正清掉被撤销的尾部。**

这是面向DSH Tavern的SQLite存储与回退增强插件：聊天、会话事件和MVU变量历史改用数据库管理，提供增量写入、按需读取、独立存档分叉与干净回退。**V1保留作者浏览器里的MVU和角色卡脚本执行方式，专注优化存储与状态一致性。**

## 功能亮点

| 特点 | 为你解决什么问题 |
|---|---|
| **SQLite增量存档** | 按聊天头字段、消息楼层拆分存储；普通局部更新只序列化、写入变化的部分，不因追加一楼就重写全部历史。会话事件使用SQLite事务与WAL管理。 |
| **历史按需读取** | 消息窗口、指定楼层和结算检查点按范围读取；后台配置只取所需头字段，场景读取只取显示相关字段。支持的按需投影路径访问哪楼才生成哪楼副本。 |
| **MVU变量历史瘦身** | 聊天与变量快照共用同一数据库连接、同一写事务，避免双库双写。旧变量树先归档再从热状态移出，近期带树楼保留默认4楼热窗口；查看旧楼时按楼层和swipe补回。 |
| **真正的物理尾部回退** | 不只是隐藏气泡：直接截断被撤销的会话事件尾部，回拨事件计数、运行轮次和写句柄，重建内存投影并清理目标轮缓存与运行痕迹。 |
| **前后台同步恢复** | 回退后通过现有连接同步受影响会话的状态、队列与任务基线；阻止旧任务、旧浏览器租约和迟到写回把被删剧情重新写回来。 |
| **原档保留，独立分叉继续玩** | 旧存档保持只读；你在面板点击「分叉迁移到数据库存档」，创建新的聊天和原生会话身份，在SQLite分叉中继续，源档与源链接保持不变。 |
| **保留作者浏览器执行体验** | MVU、角色卡脚本沿作者浏览器流程执行，不额外引入本插件的服务端卡脚本VM；作者原有的服务端提示词模板仍保留。 |
| **一条命令装卸** | 自动识别已有CLI酒馆，完整本地包优先；缺包才下载固定发行包并校验SHA256。原来运行就按原方式恢复，原来停止就保持停止，卸载保留存档。 |

### 优化为什么不止是“换个数据库”？

- **少写**：头字段与楼层分开更新，未变化的内容不重复序列化落库；不是把整档JSON塞进数据库单行。
- **少读、少复制**：复用同revision的消息摘要，采用带容量上限的缓存和按需独占副本；显示、后台配置、结算分别取各自需要的数据。
- **变量与正文一起提交**：同库同事务，变量归档失败时整笔聊天写入回滚，避免正文已保存、变量却没跟上的半态。
- **回退到真正一致的状态**：除了正文和游戏变量，还处理原生轮号、任务、派生投影、世界书投递缓存和旧写入生命周期，减少旧轮残留继续影响后续剧情的机会。

这些是已实现的优化机制，不代表每个读取接口都是常数成本：冷读、新revision和显式全量读取仍可能处理整段历史。当前公开V1没有统一的页面性能基准，因此不标注未经本代实测的“快几倍／省多少内存”。

## 一键安装

已有兼容CLI酒馆时，直接执行；无需在命令里填写版本或目录：

```sh
curl -fsSL https://raw.githubusercontent.com/huajiao1998/dsh-tavern-sqlite-v1/main/install.sh | sh
```

根目录[install.sh](<install.sh>)自动获取最新正式发行安装器。它会从`DSH_TAVERN_CLI_HOME`、`DSH_HOME`、当前目录和`~/.dsh-tavern`识别酒馆；找不到或有多个时才需要`--home`明确选择。安装前请备份并停止页面交互。

详细参数、本地离线安装、预检与失败恢复见[安装说明](<deploy/INSTALL.md>)。

## 原档怎么继续使用？

1. 安装后打开旧存档，以只读方式查看。
2. 在酒馆状态面板点击**「分叉迁移到数据库存档」**。
3. 在新创建的SQLite分叉中继续对话和回退；旧档不被自动转换或覆盖。

剧情回退针对本档的正文、游戏变量、进度和被撤销轮的运行数据；**人物卡／世界书资源库原件与独立手工编辑不会跟着剧情回退撤销。**

## 卸载与更新

```sh
curl -fsSL https://raw.githubusercontent.com/huajiao1998/dsh-tavern-sqlite-v1/main/install.sh | sh -s -- uninstall
```

卸载保留原档和数据库存档，不把SQLite存档转换回JSON。当前升级方式为先卸载旧代，再使用新发行包安装；重复执行安装不会静默升级。早期执行器的特殊处理见[安装说明](<deploy/INSTALL.md>)。

用户入口地址长期不变，新版本由最新正式Release提供；只推送main源码不会自动发布安装包。每份正式SH锁定同次发行包与SHA256，避免混装。更新详情见[更新日志](<CHANGELOG.md>)。

## 兼容与使用须知

- 当前适配**作者DSH Tavern 2.4.0、DSH／boot 0.1.5-rc.2**，需要既有Node22.19+、pnpm与CLI tavern profile；安装器面向Linux、macOS、WSL2的受支持布局，**暂不支持Desktop**。
- V1的MVU／角色卡脚本需要浏览器在线且就绪；它不是关闭浏览器也能结算的服务端执行版本。
- 安装器的60秒预算从插件包就绪后开始，失败恢复可能更久；具体平台耗时不作统一保证。源码和数据库定向验证不替代真实页面验收，安装后请登录刷新，确认历史、只读状态、手动分叉及回退。

项目名为`dsh-tavern-sqlite-v1`，内部包名保留`dsh-tavern-storage-sqlite-v1`以兼容已有装卸。本仓库只发布V1。
